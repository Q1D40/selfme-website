常见问题

开始之前，
你可能想了解。

和直接使用 Codex、Claude Code 有什么不同？

SelfMe 围绕项目目标持续发现需求，衔接评估、审阅、开发、验证与交付，并保留项目背景和工作记录，减少你反复交代背景、安排下一步和跟进结果的负担。实际工作仍由本机 Codex 或 Claude Code 完成。

开始使用，需要准备什么？

准备一个本地项目目录，并安装好可正常使用的 Codex 或 Claude Code。接入项目后，设定目标和工作范围即可开始。

需要同时安装两个 CLI，或另外配置模型 API 吗？

选择本机 Codex 或 Claude Code 中的一个即可，无需同时安装两者，也无需在 SelfMe 中额外配置模型 API。账号与模型在所选工具中配置，相关用量和费用按该工具的规则计算。

开启自动演进后，我还能决定哪些事情？

你可以设定项目目标、工作范围、运行计划，以及审阅、验收和交付的确认规则。SelfMe 按这些规则推进，遇到需要你确认或无法继续的问题时等待处理。过程中可以补充指导、暂停或停止；关闭自动演进后，仍可手动发起 AI 辅助工作。

支持哪些平台，如何选择安装包？

支持 macOS 与 Windows。下载区会自动推荐当前系统，并在能识别时匹配架构；你也可以手动选择其他安装包。版本、格式、体积与系统要求随所选安装包显示。

在哪里查看源码和参与项目？

你可以在 GitHub 查看 SelfMe 的源码与许可证、反馈问题，或参与项目贡献。
